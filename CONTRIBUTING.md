# Contribuindo

Obrigado por considerar contribuir para a plataforma Orchestrator.

## Como contribuir

1. Crie uma branch a partir de main
2. Implemente a mudança e mantenha a documentação atualizada
3. Abra um pull request com contexto claro
4. Aguarde revisão e aprovação

## Padrões esperados

- Código claro e bem documentado
- Testes quando aplicável
- Comunicação objetiva nas mudanças
