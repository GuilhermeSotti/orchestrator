# ADR-0016 — Itens de evolução futura fora do escopo até a 1.0

| Campo | Valor |
|---|---|
| Status | Aceito |
| Data | 2026-11-12 |
| Decisão | D-22 |
| Decisor | Claude, por delegação explícita do responsável pelo projeto (2026-11-12) |

## Decisão

Ficam fora do escopo até a versão 1.0 do Core: execução distribuída, agentes remotos, execução em nuvem, marketplace de plugins, registry de pacotes, dashboards, workflow engine, agendamento, automação assistida por IA, checkpoint, retomada, pausa e execução parcial.

Antecipar qualquer item exige RFC com um caso de uso real de projeto consumidor, e nenhum deles pode aumentar o Core: devem entrar como pacotes.
